简介

game-automator 是一个通用游戏自动化框架。不绑定任何特定游戏——你只需实现定位和按键映射，框架负责地图拼接、可达区编辑、A* 寻路和导航控制。

已用于 DeadMaze 项目的完整自动化闭环。

快速开始

📥 第一步：下载

从 GitHub 下载整个项目 ZIP，解压后进入 General_Generator/ 文件夹——框架就在这里。

其他文件夹（DeadMaze 主项目、截图等）是演示用例，框架本身不需要它们。

⚙️ 第二步：安装 
cd General_Generator
pip install -e .

自动安装 Python 依赖，约 1-2 分钟。

🚀 第三步：写代码 
from game_automator import GameAutomator

auto = GameAutomator("map.jpg", "reachable.png")
auto.set_route((5000, 6000), (8000, 4000))

while not auto.arrived:
    pos = get_position()          # 你的定位
    action = auto.step(pos)       # 返回 'MOVE_N'/'MOVE_NE'/...
    if action: press_keys(action) # 你的按键映射

✅ 完成。框架只做三件事：规划路径 → 接收位置 → 返回方向。定位和按键由你实现。

API 参考

构造函数

GameAutomator(
    map_path,           # str: 地图 JPEG 路径
    reachable_path,     # str: 可达图 PNG 路径
    waypoint_reach=25,  # int: 路标到达判定 (px)
    goal_reach=100,     # int: 终点到达判定 (px)
    lookahead=90,       # int: 前向路标距离 (px)
    shrink=80           # int: 边缘缩进 (px)
)

方法

方法参数返回说明
set_route(start, goal)(x,y), (x,y)List[(x,y)]规划路径, 返回完整路径点
step(pos)(x,y)str or None传入位置, 返回动作名; None=到达
cancel()--取消导航

属性

属性类型说明

接入你的游戏

框架负责"想去哪、怎么走"，你只负责"按下哪个键"。三步接入：

最少需要做的工作

步骤你要做的框架提供的
1. 映射按键写一个类，把8个方向+攻击翻译成游戏按键AbstractDriver 基类
2. 建图标定绕地图走一圈 + 涂刷可达区CLI 命令 (stitch/reachable)
3. 写定位实现 get_position() 返回角色坐标PositionTracker 可用作参考
4. 跑导航3行代码搞定GameAutomator

AbstractDriver 三个方法的作用

方法框架什么时候调用你要做什么
execute(action, ms)每帧导航步进，如"MOVE_NE"翻译成游戏按键，按下去
release_all()导航停止、卡住重规划时松开所有按键，避免角色继续乱走
click(x, y)需要交互时，如火堆点击在游戏画面的(x,y)坐标执行鼠标点击

完整示例: DeadMaze

运行此示例需要完整的 DeadMaze 项目文件（ZIP 中的 game_controller.py 和 map_tracker.py）。如果只是用框架，不需要这些。

from game_automator import GameAutomator
from game_controller import DeadMazeController  # 来自 DeadMaze 项目
from map_tracker import Tracker                  # 来自 DeadMaze 项目

# 初始化
auto = GameAutomator("map.jpg", "reachable.png")
tracker = Tracker("map.jpg", camera_id=1)
ctrl = DeadMazeController()
ctrl.find_window()

# 设定起点 (用户在地图上点击)
start = (10295, 6640)
tracker.last_position = start
tracker.need_click = False

# 规划
goal = (12489, 6231)
auto.set_route(start, goal)

# 导航循环
while not auto.arrived:
    tracker.track()
    pos = tracker.last_position
    if not pos: continue

    action = auto.step(pos)          # 框架 API
    if action is None:
        print("到达!"); break

    keys = ACT_KEYS.get(action, ['W'])
    # 先释放不需要的键
    for name in ['W','A','S','D']:
        if name not in keys:
            ctrl.key_up(getattr(ctrl, f'VK_{name}'))
    # 按下需要的键
    for k in keys:
        ctrl.key_down(getattr(ctrl, f'VK_{k}'))
    time.sleep(0.5)
    for k in keys:
        ctrl.key_up(getattr(ctrl, f'VK_{k}'))

数据流

画面采集 → 定位追踪 → 当前位置(x,y)
                          ↓
起点(x,y) + 终点(x,y) → A*寻路 → 路径点列表
                          ↓
当前位置 + 路径 → Navigator → 动作名(MOVE_NE/S/...)
                          ↓
动作名 → 用户Driver → 游戏按键

OBS 场景配置

⚠ 建图和导航需要不同的 OBS 画幅——建图时裁剪 HUD，导航时需要完整画面。

在 OBS 中：场景集合 → 导入 → 选择对应的 JSON 配置文件。

参考 DeadMaze 文档 了解具体操作。

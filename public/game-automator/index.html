简介

game-automator 是一个通用游戏自动化框架。不绑定任何特定游戏——你只需实现定位和按键映射，框架负责地图拼接、可达区编辑、A* 寻路和导航控制。

已用于 DeadMaze 项目的完整自动化闭环。

GitHub Download ZIP

3 分钟接入

from game_automator import GameAutomator

# 1. 初始化 (地图 + 可达图)
auto = GameAutomator("map.jpg", "reachable.png")

# 2. 规划路径
path = auto.set_route((5000, 6000), (8000, 4000))
print(f"路径: {len(path)} 个点")

# 3. 导航循环
while not auto.arrived:
    pos = get_position()          # 你的定位
    action = auto.step(pos)       # 返回 'MOVE_NE' / 'MOVE_S' ...
    if action:
        press_keys(action)        # 你的按键映射

API 参考

构造函数

GameAutomator(
    map_path,           # str: 地图 JPEG 路径
    reachable_path,     # str: 可达图 PNG 路径
    waypoint_reach=25,  # int: 路标到达判定 (px)
    goal_reach=100,     # int: 终点到达判定 (px)
    lookahead=90,       # int: 前向路标距离 (px)
    shrink=80           # int: 边缘缩进 (px)
)

方法

方法参数返回说明
set_route(start, goal)(x,y), (x,y)List[(x,y)]规划路径, 返回完整路径点
step(pos)(x,y)str or None传入位置, 返回动作名; None=到达
cancel()--取消导航

属性

属性类型说明
pathList[(x,y)]完整路径点列表
current_waypoint(x,y) or None当前目标路标
arrivedbool是否已到达终点

动作映射

step() 返回字符串动作名。你需要映射到游戏按键：

动作名方向DeadMaze按键
MOVE_N北/上W
MOVE_S南/下S
MOVE_W西/左A
MOVE_E东/右D
MOVE_NE东北W + D
MOVE_NW西北W + A
MOVE_SE东南S + D
MOVE_SW西南S + A
# 映射示例
ACT_KEYS = {
    'MOVE_N': ['W'], 'MOVE_S': ['S'], 'MOVE_W': ['A'], 'MOVE_E': ['D'],
    'MOVE_NE': ['W','D'], 'MOVE_NW': ['W','A'],
    'MOVE_SE': ['S','D'], 'MOVE_SW': ['S','A'],
}

完整示例: DeadMaze

from game_automator import GameAutomator
from game_controller import DeadMazeController  # DeadMaze 后台操控
from map_tracker import Tracker                  # DeadMaze ORB 追踪

# 初始化
auto = GameAutomator("map.jpg", "reachable.png")
tracker = Tracker("map.jpg", camera_id=1)
ctrl = DeadMazeController()
ctrl.find_window()

# 设定起点 (用户在地图上点击)
start = (10295, 6640)
tracker.last_position = start
tracker.need_click = False

# 规划
goal = (12489, 6231)
auto.set_route(start, goal)

# 导航循环
while not auto.arrived:
    tracker.track()
    pos = tracker.last_position
    if not pos: continue

    action = auto.step(pos)          # 框架 API
    if action is None:
        print("到达!"); break

    keys = ACT_KEYS.get(action, ['W'])
    # 先释放不需要的键
    for name in ['W','A','S','D']:
        if name not in keys:
            ctrl.key_up(getattr(ctrl, f'VK_{name}'))
    # 按下需要的键
    for k in keys:
        ctrl.key_down(getattr(ctrl, f'VK_{k}'))
    time.sleep(0.5)
    for k in keys:
        ctrl.key_up(getattr(ctrl, f'VK_{k}'))
